HOPPER STUDIO LOCAL SERVER
==========================

Windows
-------
Double-click "Start Local Server.bat" for a one-click launch that also opens
the website. You can also double-click mongoose.exe, then open:

  http://localhost:8000/

macOS (Apple Silicon)
---------------------
Double-click "Start Local Server.command". If macOS blocks the first launch,
Control-click it, choose Open, and confirm. You can also run mongoose_macos
from Terminal and then open:

  http://localhost:8000/

Keep the server window open while using Hopper Studio. Close it or press
Control-C to stop the server. The included Mongoose server serves only this
extracted Hopper Studio folder when started with either launcher.
