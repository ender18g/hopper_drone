JavaScript API reference

Every supported student-facing JavaScript command, with argument units, defaults, return values, scan freshness, and flight-safety behavior.

Lesson 04 of 9 35 min JavaScript

Learning objectives

  1. Use await on every command that returns a Promise.
  2. Choose correct units and allowed string arguments.
  3. Distinguish commands that move, scan, read stored state, or stop execution.
  4. Write a flight program that lands even when a scan or accessory command fails.
01 / 05

Four objects form the classroom API

Hopper Studio executes student code as an async function with four injected objects: drone, vision, runtime, and console.

await means “pause this program here until the command finishes.” Without it, a later command can begin while a movement or scan is still active.

Landing behavior

Normal non-event completion requests landing automatically, and errors force-land. Still write an explicit finally/land block: it documents intent and makes copied code safer outside the runner.

02 / 05

drone · flight, state, and accessories

await drone.takeOff()
Promise

Takes off and waits about 3 seconds. The real controller refuses takeoff when reported battery is 10% or lower.

await drone.land()
Promise

Zeros movement, sends the land command, and waits about 5 seconds.

await drone.hover()
Promise

Zeros all motion axes, then waits 1 second.

await drone.wait(seconds)
Promise

Waits a nonnegative duration. Invalid or negative values become 0; Stop cancels the wait.

await drone.fly(direction, seconds = 0, power = 0)
Promise

Direction: up, down, left, right, forward, or backward. Seconds are nonnegative. Power clamps to −100…100; normally use 0…100 because a negative number reverses the named direction. Includes a 2-second settle.

await drone.rotate(degrees = 0, direction = "clockwise")
Promise

Degrees are nonnegative. Direction is clockwise or counterclockwise. Uses a nominal 180°/s command and then settles.

await drone.flip(direction)
Promise

Direction: forward, backward, left, or right. Resets motion and waits about 2.5 seconds. Use only with instructor-approved clearance.

drone.setAxis(axis, power)
void

Axis: pitch, roll, yaw, gaz, or altitude (alias of gaz). Signed power clamps to −100…100 and persists until reset or replaced.

drone.reset()
void

Zeros all movement axes. It does not land.

drone.getBatteryLevel()
number | null

Returns reported battery percent or null before telemetry exists.

drone.isFlying() / drone.isLanded()
boolean

Reads the current controller state.

await drone.waitUntilBatteryLevelChanges()
Promise

Waits for new battery telemetry or cancellation. It can otherwise wait indefinitely.

await drone.takePicture()
Promise

Captures the current Studio camera/simulator view as a JPEG up to 960 px wide and adds it to the session gallery.

await drone.grabber("OPEN" | "CLOSE")
Promise

Requires the claw accessory and waits about 2 seconds.

await drone.fireGun()
Promise

Requires the cannon accessory and waits about 3 seconds.

await drone.cutoff()
Promise

Emergency motor cutoff. No controlled descent; never use as a normal stop.

await drone.manualNudge(direction, power = 30, seconds = 0.45)
Promise · advanced

Horizontal direction only. Absolute power clamps to 1…100 and time to 0.15…1.5 seconds. Ignored unless flying; normally reserved for the Studio manual-control pad.

App-owned controller methods

Do not call startRun, stopRun, abortRun, landNoWait, forceLand, disconnect, or telemetry callback fields from student code. The Studio owns connection and emergency behavior.

03 / 05

vision · pixels, detectors, and stored coordinates

await vision.scanThreshold(threshold = 60, invert = false, announceScan = true)
ThresholdResult

Fresh scan at up to 320 px wide. Threshold clamps to 0…100. Result fields: threshold, invert, whiteCoverage, blackCoverage, centerWhite, frameWidth, frameHeight, binaryData. Set announceScan false only to suppress the Studio scan animation/event.

await vision.seesBinary(color, threshold = 60, invert = false, minimumCoverage = 10)
boolean

Fresh scan. Color is white or black. Coverage clamps to 0…100%.

await vision.binaryCenter(color, threshold = 60, invert = false)
boolean

Fresh scan; tests only the center reticle pixel.

await vision.loadObjectModel()
ObjectDetection

Loads the local COCO-SSD model once. Requires a local/hosted server; direct file:// loading is unsupported.

await vision.detectObjects(minimumConfidence = 0.55, announceScan = true)
VisionDetection[]

Fresh scan. Confidence is 0…1. Real inference returns at most 10 boxes with bbox, class, score, frame size, centerX, and centerY. Set announceScan false only to suppress the Studio scan animation/event.

await vision.seesObject(label, minimumConfidence = 0.55)
boolean

Fresh scan and case-insensitive exact COCO class match.

vision.objectCoordinate(label, axis, minimumConfidence = 0.55)
number

No fresh scan. Reads the last stored coordinate for x or y, from −100 to +100; right/up are positive. Returns 0 before a match or when stored confidence is too low.

await vision.scanAprilTags(announceScan = true)
AprilTagDetection[]

Fresh tag36h11 scan at up to 520 px wide. Set announceScan false only to suppress the Studio scan animation/event.

await vision.seesAprilTag(id = "any")
boolean

Fresh scan. ID is any or a number from 0 through 586.

await vision.centerOnAprilTag(drone, id = "any", translationPower = 10, centerSlack = 5, angleSlack = 5, lostTagSearches = 3)
boolean

Pulses roll/pitch and image-plane yaw for up to 30 seconds. Returns true only when position and angle tolerances are met. No altitude, distance, or collision control.

await vision.loadCustomModel(modelFile, weightsFile, metadataFile)
Promise · advanced

Loads the three Teachable Machine File objects and returns their metadata labels. The Vision Testing file picker normally owns this step.

await vision.classifyCustomModel(announceScan = true)
CustomPrediction[]

Fresh whole-frame Teachable Machine classification. Requires model.json, weights.bin, and metadata.json loaded in Vision Testing. Set announceScan false only to suppress the Studio scan animation/event.

await vision.seesCustomLabel(label, minimumConfidence = 0.75)
boolean

Fresh classification and case-insensitive exact label match.

await vision.capturePhoto(maxWidth = 960)
Promise<{ blob, width, height }> · advanced

Captures the current source as a JPEG-backed photo record. The injected drone.takePicture() wrapper is the normal student command because it also stores the result in the gallery.

Object coordinates are normalized around the image center:

xn=200(xcW−12),yn=−200(ycH−12)x_n = 200\left(\frac{x_c}{W}-\frac{1}{2}\right),\qquad y_n = -200\left(\frac{y_c}{H}-\frac{1}{2}\right)

The detection-box center (x_c, y_c) becomes −100…+100. The minus sign makes up positive even though pixel rows increase downward.

Stored means stale is possible

objectCoordinate() remembers a prior match. A later missed scan does not erase that coordinate. Call seesObject() or detectObjects() when a decision requires current visibility.

04 / 05

runtime and console · events and program life

runtime.registerKey(kind, key, asyncHandler)
void

Kind is pressed or released. Keys include lowercase letters, ArrowUp/Down/Left/Right, and Space. Repeated handlers can overlap.

runtime.registerDrone(eventName, asyncHandler)
void

Event names: flying, landed, crashed, batteryLevelChanged.

runtime.keyIsPressed(key)
boolean

Polls the current normalized keyboard state.

await runtime.repeatForSeconds(seconds, asyncHandler)
Promise

Runs the handler sequentially until the nonnegative duration expires or the program stops.

await runtime.tick()
Promise

Yields to the browser and throws Program stopped after cancellation.

runtime.stop()
void

Stops execution, removes event listeners, and resets/aborts motion. It does not send a land command.

runtime.stopped / runtime.hasEvents
boolean

Read-only program-state flags for loops or diagnostics.

console.log(...values)
void

Writes an informational line to the Studio console.

console.warn(...values) / console.error(...values)
void

Writes warning or error lines to the Studio console.
