A complete, student-facing map of every Hopper block category, including defaults, units, fresh-scan behavior, and safety consequences.

Lesson 03 of 9 22 min Blocks

Learning objectives

  1. Build a program from events, commands, values, and control-flow blocks.
  2. Choose a fresh vision scan when a decision depends on the current frame.
  3. Recognize persistent motion commands and reset them deliberately.
  4. End every flight path with a safe landing strategy.
01 / 05

Shape is grammar

Blockly prevents many syntax errors by making only compatible shapes connect. That does not guarantee a sensible or safe program.

Hat block

Event or program start

Starts a stack when Run is pressed, a key changes, or a drone event occurs.

Statement block

Do something

Commands such as take off, wait, scan, fly, print, and land connect vertically.

Value block

Produce data

Rounded blocks produce numbers, text, or booleans that fit into inputs.

Container

Control flow

If, loop, and function blocks contain statements and decide when they run.

Execution model

A normal non-event program automatically requests landing when it reaches the end. Event-driven programs remain alive until stopped. The Stop button force-lands; the “stop program” block only stops/reset motion and does not itself land.

Percent versus fraction

Blocks and sliders display confidence as 55%. JavaScript and Python use 0.55. Mixing these scales is a common reason a detector appears to find nothing.

05 / 05

Logic, loops, math, variables, and functions

Logic

Decide

If/else, comparison, and/or, not, booleans, and ternary choice blocks combine facts into decisions.

Loops

Repeat with an exit

Forever, for-seconds, repeat-count, while/until, counted-for, break, and continue blocks control repetition.

Math

Transform numbers

Arithmetic, roots/functions, trigonometry, rounding, modulo, and random-number blocks support calculations.

Variables

Remember

Store thresholds, counters, scan results, and state. Name variables by meaning and unit.

Functions

Reuse

Group a sequence into a named procedure. Keep flight functions short and make their preconditions clear.

A forever loop that contains no wait or awaited command can monopolize the browser. Include a timed command, wait, or a clear stop condition.

Check your understanding · Which block should follow a persistent “set roll to 10%” command?

Use reset movement after the intended interval, or use a timed fly block instead. A persistent axis command continues until another command changes it.
