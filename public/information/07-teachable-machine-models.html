Teach a classifier with examples

Teachable Machine image models

Design classes, collect balanced evidence, export the correct three files, and understand why a whole-frame classifier is not an object detector.

Lesson 07 of 9 26 min Custom machine learning

Learning objectives

  1. Choose class definitions that match a real decision.
  2. Collect balanced train/validation examples across likely conditions.
  3. Export and load model.json, weights.bin, and metadata.json together.
  4. Explain input shape, output shape, and why parameter count varies by export.
01 / 05

Classification labels the whole frame

A Teachable Machine image model returns one score for each class you created. It does not automatically locate the object with a bounding box.

Input

A square image crop

The library center-crops the current frame and resizes it to the export metadata image size; the standard workflow defaults to 224 × 224 RGB.

Features

A MobileNet-family backbone

Transfer learning reuses visual features from a compact image network, then learns a small class-specific output head.

Output

One score per class

With k classes, the output vector has k entries. Hopper returns every label in metadata order as className and probability.

Runs where?

On the host

Hopper Studio loads the files and runs inference locally in the browser/desktop app, not on the flight controller.

Not a fixed architecture

The uploaded export determines the class count, exact graph, and coefficient count. Do not quote one universal Teachable Machine parameter number. Inspect the actual model.json and weight manifest when an exact count matters.

Your class design defines the question

A two-class model called “landing pad” and “not landing pad” asks a useful decision question. A model called “Class 1” and “Class 2” hides what the examples mean.

03 / 05

Collect evidence, not duplicates

  1. Create a Standard image model, not the embedded 96 × 96 grayscale option.
  2. Name the target class and a deliberately broad background/other class.
  3. Record short bursts from different positions instead of many near-identical consecutive frames.
  4. Separate a test set before training. Do not tune repeatedly on the same examples and call it validation.
  5. Inspect a confusion matrix or at least a table of expected versus predicted labels across the held-out set.
softmax⁡(zi)=ezi∑j=1kezj\operatorname{softmax}(z_i)= \frac{e^{z_i}}{\sum_{j=1}^{k}e^{z_j}}

A common final layer converts k class logits into scores that sum to 1. High relative score does not guarantee real-world correctness.

04 / 05

Hopper expects exactly three files

FileRoleHopper requirement
model.jsonGraph topology plus references to weight dataChoose the exported TensorFlow.js model file.
weights.binStored numeric coefficientsChoose the matching binary file from the same export.
metadata.jsonLabels, image size, and package metadataFilename must be metadata.json in the current UI.

Load all three together in Vision Testing. The Studio returns the metadata labels, center-crops the current frame, uses no horizontal flip, and evaluates the whole frame.

05 / 05

Measure performance in the deployment scene

precision=TPTP+FP,recall=TPTP+FN\text{precision}=\frac{TP}{TP+FP},\qquad \text{recall}=\frac{TP}{TP+FN}

Precision asks how many positive predictions were correct. Recall asks how many real positives were found.

False positive

Unsafe enthusiasm

The model announces the target when it is absent. Add hard negatives and require repeated confirmation.

False negative

Missed target

The target is present but scores below threshold. Add diverse target examples and improve framing.

Shortcut

Background leakage

The model learns a table, hand, or lighting pattern rather than the intended object.

Drift

Camera mismatch

Training webcam imagery differs from the drone feed in crop, exposure, blur, or viewpoint.

Package compatibility note

The course app uses @teachablemachine/image 0.8.5 with TensorFlow.js 4.22.0 even though the older library declares a 1.3.1 peer. Treat custom-model replacement and disposal as a tested compatibility requirement for this build.

Check your understanding · Why can a three-class model have a different parameter count from a five-class model?

The final classification head has one output per class. Changing k changes the final weight matrix and bias vector; different Teachable Machine export versions can also change the backbone or metadata.
