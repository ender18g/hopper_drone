01 / 06

This looks like Python and runs through a transpiler

Hopper Studio translates a deliberately limited Python-like language into the same asynchronous JavaScript API used by the Blocks and JavaScript editors.

Convenience

No await keyword

Supported Hopper commands automatically wait when translated. Writing await is rejected.

Scope

Classroom subset

Assignments, decisions, loops, simple functions, exceptions, break/continue, return, raise, and assert are supported.

Not supported

Not CPython

Imports, classes, async, lambda, with, yield, and other advanced statements are rejected.

Returned data

JavaScript field names

Objects keep fields such as whiteCoverage, centerX, className, and probability.

Defaults now match the reference

The transpiler materializes documented optional values before calling the JavaScript runtime. Even so, explicit flight duration and power are clearer and safer than relying on defaults.

Flight, state, and accessory commands

take_off()
None

Takes off and waits for stabilization.

land()
None

Zeros movement, sends land, and waits.

hover()
None

Zeros motion axes and waits 1 second.

wait(seconds)
None

Waits a nonnegative duration.

fly(direction, seconds=1, power=15)
None

Direction: up, down, left, right, forward, backward. Power is normally 0…100%. Specify duration and power in flight code.

rotate(degrees=0, direction="clockwise")
None

Direction: clockwise or counterclockwise.

flip(direction)
None

Direction: forward, backward, left, right. Requires clearance.

set_axis(axis, power)
None

Axis: pitch, roll, yaw, gaz, or altitude. Signed −100…100 and persistent.

reset_motion()
None

Zeros axes. Does not land.

battery_level()
number or null-like value

Reported battery percentage when telemetry exists.

is_flying() / is_landed()
bool

Reads the controller state.

wait_for_battery_change()
None

Waits for new battery telemetry or program cancellation.

take_photo()
None

Captures and stores the current Studio camera/simulator frame.

open_grabber() / close_grabber()
None

Requires the claw accessory.

fire_gun()
None

Requires the cannon accessory.

emergency_cutoff()
None

Immediately stops motors; emergency only.

Vision commands

scan_threshold(threshold=60, invert=False)
ThresholdResult

Fresh binary scan. Fields use camelCase: whiteCoverage, blackCoverage, centerWhite, frameWidth, frameHeight.

sees_binary(color, threshold=60, invert=False, coverage=10)
bool

Fresh scan; color is white or black; coverage is percent.

binary_at(color, x=0, y=0, threshold=60, invert=False)
bool

Fresh scan at one normalized pixel. Center is 0,0; top right is 100,100.

load_object_model()
model

Loads the local COCO-SSD model. Usually the first object scan can load it automatically.

scan_objects(confidence=0.55)
detections

Fresh COCO-SSD scan. Confidence is 0…1.

detect_objects(confidence=0.55)
detections

Exact alias of scan_objects.

sees_object(label, confidence=0.55)
bool

Fresh scan and exact case-insensitive COCO label.

object_coordinate(label, axis, confidence=0.55)
number

Stored coordinate, no fresh scan. Axis x or y; −100…100; right/up positive.

object_x(label, confidence=0.55) / object_y(...)
number

Convenience wrappers for stored x or y.

center_on_object(label, power=10, confidence=0.55, center_slack=5, lost_searches=3, rescan_delay=0.5)
bool

Bounded object-box centering loop using roll/pitch only. It never changes yaw.

scan_april_tags()
tag detections

Fresh tag36h11 scan.

sees_april_tag(id="any")
bool

Fresh scan; any or ID 0…586.

center_on_april_tag(id="any", power=10, center_slack=5, angle_slack=5, lost_searches=3, rescan_delay=0.5)
bool

Bounded 2D centering/alignment loop that waits for a level image before rescanning.

scan_custom_model()
predictions

Fresh whole-frame Teachable Machine classification.

sees_custom_label(label, confidence=0.75)
bool

Fresh classification and exact label.

04 / 06

Program state and keyboard helpers

stopped()
bool

True after the runtime is stopped; useful in a while loop.

key_pressed(key)
bool

Keys: lowercase letters, ArrowUp/Down/Left/Right, or Space.

print(*values)
None

Writes values to the Studio console.

Always yield

A while loop should contain wait() or another waiting Hopper command. Otherwise it can monopolize the browser and delay Stop handling.

Portable thinking

Use this editor for course missions, not as a general Python interpreter. If a language edge case matters, rewrite it in a simple explicit form or test it in real CPython separately.

06 / 06

Supported control flow

Supported statements include assignments, if / elif / else, while, for … in, simple def, try / except / finally, break, continue, pass, return, raise, and assert. User-defined function parameters must be simple names; default-valued parameters and type annotations are not supported.

Check your understanding · Why does the example call land() inside finally?

The finally block runs after the try body whether it succeeds or raises an error. It documents and enforces the mission’s safe terminal action.
